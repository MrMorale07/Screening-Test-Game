# Game Idea Generator

When asked for game ideas, follow these steps:

1. If the user hasn't said, ask for a theme (for example space, animals, food).
2. Give 3 ideas. For each one include:
   - A title
   - The objective (what the player must do)
   - The main mechanic (matching, quiz, collecting)
   - How the player wins and how the game ends
3. Keep every idea small enough to build in one day.
4. For quests, always include a goal, a reward, and a clear ending.
5. Make sure the game can be played with both touch (mobile) and mouse (desktop).
